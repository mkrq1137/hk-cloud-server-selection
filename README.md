## 常见问题

**香港云服务器真的不用备案吗？**
不用。香港节点不在内地 ICP 备案体系内，这也是各家厂商把它列为核心卖点的原因，开通后即可绑定域名上线。

**2核1G 能跑什么业务？**
静态博客、企业官网、轻量应用和脚本类业务都没问题。要跑 Java 应用或自带数据库的动态站点，1G 内存会比较吃紧，这类需求直接看 2核4G 档位。

**CN2 线路一定要买吗？**
看访客在哪。大陆用户占多数，CN2 带来的速度提升是实打实的；访客以海外为主，普通国际带宽就够，为用不上的线路加钱没有意义。

**活动价会不会是套路？**
价格本身是真实活动价，但有两个变量要自己确认：库存（热门款常年断货）和续费价（活动价通常只覆盖首购期）。
